# Label Protocol

## Label source hierarchy (best to worst)

1. `measured_reference` — direct measurement by calibrated equipment
2. `cycler_reference` — reported by battery cycler software
3. `coulomb_counted_dynamic_capacity` — CC with per-cycle capacity estimation
4. `coulomb_counted_fixed_capacity` — CC with nominal capacity
5. `pseudo_label` — generated by another model
6. `unavailable` — no SOC labels exist

## Rules

- Target-domain test labels must never be used during training.
- Pseudo-labels are soft training signals, not ground truth.
- Always report `label_source` alongside metrics.
- CMU eVTOL evaluations must use proxy references (see `docs/cmu_evtol_protocol.md`).
